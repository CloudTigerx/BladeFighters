# BladeFighters User Guide

## 🎮 **Welcome to BladeFighters!**

BladeFighters is a puzzle-fighting game that combines strategic puzzle gameplay with intense combat mechanics. This guide will help you get started and master all the features.

## 🚀 **Quick Start**

### **Getting Started**
1. **Launch the Game**: Run the game executable or use the provided scripts
2. **Main Menu**: Navigate using arrow keys and Enter
3. **Quickplay**: Jump right into single-player puzzle action
4. **Test Mode**: Practice with advanced features and AI opponents
5. **Settings**: Customize your experience before playing

### **Basic Controls**
- **Arrow Keys**: Move pieces left/right
- **Up Arrow**: Rotate pieces
- **Down Arrow**: Soft drop (accelerate falling)
- **Space**: Hard drop (instant placement)
- **Escape**: Pause/return to menu
- **F9**: Toggle Input Feel Tuner (advanced)

## ⚙️ **Settings & Customization**

### **Graphics Settings**
Access settings from the main menu or press the settings key during gameplay.

#### **Display Options**
- **Resolution**: Choose from optimized resolutions for your display
- **Fullscreen**: Toggle fullscreen mode
- **Borderless**: Windowed mode without borders
- **V-Sync**: Enable/disable vertical synchronization
- **UI Scale**: Adjust interface size (0.8x to 1.5x)
- **Brightness**: Adjust game brightness (0.3 to 1.0)

#### **Visual Effects**
- **Particle Effects**: Enable/disable visual particle effects
- **Show FPS**: Display frames per second counter
- **Native Fullscreen**: Use native resolution for high-DPI displays

### **Audio Settings**
- **Master Volume**: Overall game volume (0.0 to 1.0)
- **Music Volume**: Background music volume (0.0 to 1.0)
- **Sound Effects**: Individual sound effect volume

### **Input Settings**
- **Input Feel Tuner**: Press F9 during gameplay to access
- **Repeat Initial Delay**: Time before key repeat starts (milliseconds)
- **Generic Repeat Interval**: Standard key repeat rate
- **Move Repeat Interval**: Arrow key repeat rate
- **Rotate Repeat Interval**: Rotation key repeat rate

### **Control Rebinding**
- **Navigate to Controls tab** in settings
- **Click on any control** to rebind
- **Press the new key** to assign
- **Settings save automatically**

## 🧩 **Puzzle Gameplay**

### **Basic Mechanics**
- **Falling Pieces**: Control falling puzzle pieces
- **Line Clearing**: Complete horizontal lines to clear them
- **Chain Reactions**: Create multiple line clears for combos
- **Garbage Blocks**: Receive attack blocks from opponents

### **Advanced Techniques**
- **Cluster Formation**: Create 2x2 or larger clusters for special attacks
- **Breaker Blocks**: Special blocks that clear surrounding areas
- **Micro-movements**: Precise piece positioning
- **Wall Kicks**: Advanced rotation techniques

### **Scoring System**
- **Single Line**: Basic points
- **Double/Triple**: Bonus multipliers
- **Tetris (4 lines)**: Maximum points
- **Chain Reactions**: Combo multipliers
- **Cluster Attacks**: Special attack points

## ⚔️ **Combat System**

### **Attack Types**
- **Garbage Blocks**: Basic attack blocks sent to opponent

## 🐛 **Troubleshooting**

- **Check Dependencies**: Ensure Python and pygame are installed

- **Update Drivers**: Update graphics drivers

#### **Performance Issues**
- **Lower Resolution**: Try a lower resolution setting
- **Disable Effects**: Turn off particle effects
- **Update Drivers**: Ensure graphics drivers are current
- **Close Background Apps**: Free up system resources

#### **Input Problems**
- **Check Key Bindings**: Verify control settings
