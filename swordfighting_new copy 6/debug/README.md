# Debug Scripts

This directory contains debugging and demonstration scripts for the swordfighting game.

## Contents

- `debug_*.py` - Various debugging scripts for testing specific game mechanics
- `cascade_timing_demo.py` - Demonstrates cascade timing behavior
- `timing_demo.py` - General timing demonstration

## Usage

Run these scripts from the project root directory:

```bash
python debug/debug_cascade.py
python debug/cascade_timing_demo.py
```

These scripts are for development and debugging purposes only.
